# 模型可信度與研究界線

1. 不要以生成式 Agent 的「像真人」當作實證效度。行為參數要有資料來源／研究假設。
2. 未校準時，顯示「模型條件下的模擬結果」，不可宣稱真實活動會有相同概率。
3. 加入年齡、性別、障礙狀態等資訊不代表可以用刻板印象決定性格或能力；直接建模必要的資訊服務、可及性與行為需求。
4. LLM 只能提出動作；WorldEngine 驗證權限、資源與時序，並拒絕違規行動。
5. 同一 seed 模擬若 LLM 重呼叫，仍可能不重現，重播時要使用已儲存的 LLM 決策。
6. 研究至少包含靜態 LLM 分析、多 Agent 對話、人工建立模擬、Plan2Sim；並評估純 DES 到複雜人因模型的消融差異。
7. 重要專案資料與個資不可直接寄給未經批准的第三方模型；採最小化、保留期限與存取控制。
